# Task1 C程序编译流程
一个C语言`.c`源码到最终可执行程序，分为**预处理、编译、汇编、链接**四个阶段：

1. **预处理（gcc -E）**
只做文本替换，不检查语法。处理#include头文件、#define宏定义、条件编译，删除注释。输出`.i`预处理后的C源码。

2. **编译（gcc -S）**
将预处理后的C代码翻译成汇编代码，同时做语法、类型检查。如果代码少分号、类型错误会在这里报错。输出`.s`汇编文件。

3. **汇编（gcc -c）**
把汇编指令翻译成机器二进制，生成目标文件`.o`。目标文件是二进制，但还不能独立运行，存在未解析的函数符号。

4. **链接**
把多个`.o`目标文件加上系统库文件合并，解析函数地址（例如printf），最后生成Linux可执行程序。
如果函数只声明没实现，会在链接阶段报未定义引用错误。

## 命令观察
- `gcc -E main.c -o main.i`：生成预处理后的源码，可以看到宏被展开、头文件内容被粘贴进来。
- `gcc -S main.i -o main.s`：生成汇编文本，可以看到C代码对应的汇编指令。
- `gcc -c main.s -o main.o`：生成二进制目标文件，用文本编辑器打开会乱码。
